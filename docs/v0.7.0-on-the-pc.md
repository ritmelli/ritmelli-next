# v0.7.0 on the PC

v0.7.0 left these names on each PC. The new line reads and writes the same ones, so each name in
`src/ritmelli/machine/installed.py` stays as it is. One line per name:

- `APP_ID`: Windows takes any setup with this id as the same program. `installer/ritmelli.iss` writes it `{{...}`.
- `UPDATE_TASK`: the update task. `machine/fixtures/v0.7.0/update-task.xml` is the file v0.7.0 hands to schtasks.
- `MIC_TASK`: the task of the mic setup. `machine/fixtures/v0.7.0/mic-task.xml` is its file.
- `UPDATE_MODE`: what the update task, the setup and the uninstall log of v0.7.0 run. Alone, it is the round.
- `UPDATE_ACTIONS`: `tarefa`, which the setup runs to create the update task, and `remove`, which the uninstaller runs.
- `MIC_MODE`: what the mic task, the setup and the uninstall log of v0.7.0 run for the mic setup.
- `MIC_ACTIONS`: `instala-todos`, which puts the filter on each microphone, and `remove`, which gives each one back.
- `HOOK_KEY`: the key of the hook, in HKLM, which only an administrator writes.
- `FILTER_CLSID`: the filter, on the EFX and LFX slots. The FxProperties of each microphone point at it.
- `HOST_CLSIDS`: the hosts, one per vendor MFX. The FxProperties point at them too, so no CLSID ever changes.
- `OUR_CLSIDS`: the filter and the hosts.
- `APO_KEY`: the registration of each APO, ours and the vendors'.
- `CAPTURE_KEY`: the microphones, each by its id, with its Properties and FxProperties.
- `SAVED_KEY`: the key of the mic setup, in HKLM: the original slots of each microphone. v0.7.0 wrote no DLL digest there.
- `HOSTED`: at the root of `SAVED_KEY`, `_hospede<n>` is the vendor MFX that host n runs. The filter reads it.
- `SAVED_VERSION`: the version of the copy the mic setup writes: 3 holds the MFX list too.
- `SILENT`: at the root of `SAVED_KEY`, the devices the last check found silent, which the app reads.
- `MISSING`: next to the original slots, the slots the mic setup created. They come off when the original comes back.
- `ENHANCEMENTS_OFF`: next to the original slots, 1 when the audio enhancements were off.
- `COPY_VERSION`: next to the original slots, the version of the copy.
- `_FX`: the property set of the slots, values of FxProperties.
- `_MODES`: the property set of the processing modes of a slot.
- `ASSOCIATION`: without it Windows reads no slot.
- `LFX`: a driver with no processing modes reads only this slot.
- `GFX`: saved with the original slots and given back.
- `SFX`: the vendor single SFX. The mic setup leaves it as it is.
- `MFX`: the vendor single MFX. It goes first on `MFX_LIST` when the MFX modes have DEFAULT and RAW.
- `EFX`: the vendor single EFX. It goes first on `EFX_LIST`.
- `MFX_LIST`: the MFX in order. Windows takes an echo canceller only as the last one.
- `EFX_LIST`: the EFX in order, which runs for every stream, raw included. The filter is the last one.
- `SFX_MODES`: the processing modes of the SFX.
- `MFX_MODES`: the processing modes of the MFX list. A host takes the last place only with DEFAULT and RAW.
- `EFX_MODES`: the processing modes of the EFX list. The mic setup adds DEFAULT and RAW.
- `MODE_DEFAULT`: the default processing mode.
- `MODE_RAW`: the raw processing mode.
- `ANY_NODE`: the association the mic setup writes when a microphone has none.
- `NO_ENHANCEMENTS`: in Properties, 1 turns the audio enhancements off, and then no effect loads.
- `SAVED_SLOTS`: what the mic setup saves before it puts the filter on.
- `CREATED_SLOTS`: the slots the mic setup may create. The missing ones go in `MISSING`.

Outside `installed.py`:

- `DOWNLOADING` in `update/client.py`: the name v0.7.0 gives a download cut in the middle. Its clean-up deletes it.
- `nova` in `estado.json`: the keys v0.7.0 writes there. `parcial` is always false: the new line has no partial setup.
