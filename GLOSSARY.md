# Glossary

One English name per concept. The Portuguese term is on the left. Use the English name in code and docs.

- achado = finding (a problem a review reproduced, kept as the GitHub issue `finding: <name>`)
- anel = ring
- escapou da regra = rule-missed (the label of a finding that came back after its lint rule)
- ficha = kind (a kind of change, in kinds.toml)
- filtro = filter (the audio effect DLL, an APO, that the microphone passes through)
- folga = headroom
- gancho = hook (the Manifesto, Chave and SoHttps values in HKLM\SOFTWARE\Ritmelli\Atualizador)
- hospedeiro = host (our APO that takes a vendor MFX slot and runs the vendor APO inside it)
- montagem de teste = test build (a setup built from main for the crossing, never published)
- passagem = transition
- pasta protegida = protected folder
- prateleira = shelf
- prato = deck
- preparo do microfone = mic setup (the --microfone mode: puts the filter on each microphone and takes it off)
- promover = promote (the label of a finding that two PRs had: it becomes a lint rule)
- resumo dos fontes = sources digest (a sha256 that changes only when a filter source changes)
- rodada = round (one run of the update task)
- seca = dry-out
- travessia = crossing (a PC going from v0.7.0 to the new line, and from each version to the next)
- vaga = slot (one effect place in the FxProperties of a microphone)
